# Install and update

[User guide](EN-Home.md) · [Release status](EN-Releases.md) · [Getting started](EN-Getting-Started.md)

## Windows

1. Download the x64 ZIP from [Windows Releases](https://github.com/KaanKaya17/InstagramTracker-Downloads/releases/latest).
2. Extract the entire ZIP to a folder. Open **InstagramTracker.exe** from the extracted folder, keeping **resources** and the other files beside it. Python is bundled.
3. On **Overview**, open an Instagram ZIP or connect an account for live tracking.

The EXE is unsigned. The GitHub release lists the ZIP’s SHA-256 digest. Keep the original package together and download it from the project’s release page.

To update, choose **Quit completely** from the old instance’s tray menu. Extract the new ZIP to its own folder and open the new EXE. One version should use the encrypted data store at a time. [Back up your records](EN-Privacy.md#backups-and-exports) if you want a recovery copy.

## Android

Android 7.0 (API 24) or later is required. Use the signed APK listed under [release status](EN-Releases.md#android). Open it on your phone and, if Android asks, grant installation permission to the file manager or browser you are using. You can turn that permission off after installation. USB debugging and an emulator are unnecessary for normal installation.

Updates signed with the same key install over the existing app. Uninstalling or clearing app data can remove locally encrypted records. To use system notifications, enable them in Android and in Tracker.

## Web

The web preview displays sample data. Use the Windows application for continuous live monitoring while the computer is running.
