# Görsel incelik doğrulaması — Windows/web 0.2.16 / Android 0.1.36

29 Ekim 2026. Görsel değişiklikler sentetik verilerle gerçek paketlenmiş Windows EXE'de, tarayıcı önizlemesinde ve Android debug emülatöründe kontrol edildi. Üretim hesabı kullanılmadı. Yeni sürüm görünüm değişikliğidir; önceki Android giriş/429 sorununun çözüldüğü iddia edilmez.

## Görsel kapsam

- CSS'te gerçek sayısal alanlar seçilir: ana istatistik, kişi/listenin takipçi sayısı, grafik özeti/ekseni, olay saati ve ayrıntı sayıları. OpenType tabular/lining figures etkinleştirilir; kullanıcı adı/biyografi/notlara genel harf aralığı uygulanmaz. Basamak sayısının artması hâlâ daha fazla alan gerektirebilir. Android ana sayaç/kişi sayıları ve ortak profil özetinde aynı font özellikleri kullanılır. Profil özetinde API 26+ uzun sayılar mevcut sütuna tek satırda uyarlanır; API 24–25 tek satır/ellipsis kullanır, metnin tam değeri erişilebilir kalır.
- Windows/web basma geri bildirimi 120 ms içinde 1 px aşağı harekettir; geniş kartları küçültmez, yerleşim ölçülerini değiştirmez. Hover hareketi 3 yerine 2 px'tir. Disabled kontroller basma hareketi almaz. Reduced motion'da transform ve geçişler kapalıdır. Android native ripple rengi birincil mor zeminde açık, diğer yüzeylerde temanın vurgu rengidir; dokunma/klavye eylemi değiştirilmez.
- `design/theme.json`, `surfaceHighlight` ve `scrollThumb` renklerinin sahibidir. Mevcut üretici CSS ve native UiPalette çıktısını üretir. Sistem koyu modu, açık, koyu ve OLED aynı renkleri kullanır. Kartların mevcut kenarı korunur; üstte ince iç ışık eklenir. OLED'de dış gölge yoktur ve ana zemin siyah kalır. Android kart ışığı statik bir çizimdir; shader yalnız sınır değişiminde hazırlanır. Yeni animasyon veya zamanlayıcı yoktur.
- Windows/web kaydırma çubuğu 10 px alan içinde yuvarlak başparmak kullanır. Forced-colors modunda özel WebKit stilleri devreye girmez. Android ana ScrollView ve takip listesinde 4 dp native gösterge vardır; API 29+ rengi ortak paletten gelir, önceki API'lerde native tema kullanılır. Gösterge içeride ve yerleşimi değiştirmeyen overlay'dir. Genel cam/blur efekti ve sürekli izleme nabzı eklenmedi.

## Çalıştırılan kontroller

- `npm run theme`, `npm run check`: ortak palet üretimi, 860 TR/EN mesajı ve JavaScript kaynak denetimi geçti. `scripts/check-locales.py`: 584 eşleşen Android kaynağı/placeholder denetimi geçti.
- Python backend: 156 test geçti. Node desktop: 28 test geçti. Worker yeniden PyInstaller ile derlendi; sürüm 0.2.16 olarak yeni klasöre paketlendi.
- Yeni EXE'de `check-functional-desktop.mjs` 30, `check-accounts-desktop.mjs` 10, `check-progress-desktop.mjs` 11 kontrol geçti. Gerçek IPC/DPAPI ve ayrı TrackerQA kasaları kullanılır; worker offline'dır. Tema, gezinme, yerel yedek/CSV, hesap geçişi, kontrol ilerlemesi ve kayıtlı mola kapsamı korunur.
- `check-appearance.mjs`: 8 Windows/web senaryo grubu geçti. Üç tema metin kontrastları, native Windows tema eşlemesi, altı Windows rotası, modal/arama paleti/arşiv, Sistem tema değişimi, yeniden açılış ve webin masaüstü/390 px görünümleri doğrulanır. Yatay taşma, JavaScript hatası veya dış kaynak isteği gözlenmedi.
- Gerçek EXE üzerinde ek görsel incelemede açık/koyu/OLED ana ekran görüntüleri alındı. Ana sayacın 45 px fontunda `111111` ve `888888` örnekleri her temada aynı **141,8125 CSS px** genişlikte ölçüldü. Bu tek makine/font ölçümüdür; bütün font/işletim sistemi kombinasyonları için ölçüm değildir. Scroll thumb / yüzey kontrastı sırasıyla **3,29:1**, **3,81:1**, **4,10:1**; tutma alanı 10 CSS px'tir. Basılı durum 1 px, reduced motion durumu `transform:none` / geçiş `0s` olarak gözlendi. Hesap ve gate kaydı değişmedi, dış istek ve JS hatası yoktu. İlk yerel ölçüm yardımcısında fareyi aynı kartta bırakmak listeye geçirdi; ölçüm tamamlanamadı. Yardımcı fareyi kontrol dışında bırakarak düzeltildi; uygulama hatası olarak değerlendirilmedi.
- Android `:app:testDebugUnitTest :app:lintRelease :app:assembleRelease :app:assembleDebug :app:assembleDebugAndroidTest`: 88 JVM testi ve release lint/derleme geçti. ProfileSummary'nin son değişikliğinden sonra derleme ve ilgili emülatör testleri tekrarlandı.
- API 37 Small_Phone emülatöründe AppearanceFlowTest, LanguageFlowTest, ClarityFlowTest ve MemberProfileFlowTest: toplam 16 test geçti. Tema/dil seçimi ve yeniden oluşturma, mevcut kayıt/mola, 100 kişinin yerel sayfalaması, liste üyesi profili ve ekleme/izleme akışları sentetik servislerle sınandı. Ekran görüntüleri sahte preview hesabına aittir. Tema penceresinin çıkış animasyonunu fotoğrafa karıştırmamak için yalnız testte ekran yakalama beklemesi eklendi; ana ekran ve kişiler üç temada ayrıca yakalanır.

## Sınırlar ve dağıtım

Gerçek hesap girişi, üretim Instagram ağ yanıtları, fiziksel telefon, API 24/25 ve API 29 altındaki native scrollbar görünümü bu değişiklikte yeniden doğrulanmadı. CPU/GPU, pil tüketimi veya bellek farkı ölçülmedi; yalnız statik efektlerin ve mevcut olaylarla çalışan kısa geri bildirimin kullanıldığı kaynak incelemesiyle bilinir. Native ripple'ın görünümü Android sürümüne göre değişebilir. Web hâlâ örnek veri önizlemesidir.

Windows ZIP tamamen çıkarılır; eski uygulamada tepsi → Tamamen çık yapılıp yeni EXE açılır. Android aynı üretim anahtarıyla imzalanan APK ile mevcut uygulama üzerine güncellenir. Paket/izin/imza kontrolü dağıtım öncesinde mevcut `scripts/verify-release.py` ile yapılır. Önceki sürüm dosyaları değiştirilmez. Görsel güncelleme için hesap çıkışı veya yeniden parola girişi gerekmez.
