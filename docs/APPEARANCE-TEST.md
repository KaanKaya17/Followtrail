# Koyu tema — Windows/web 0.2.11, Android 0.1.32

2026-10-28. Sistem / Açık / Koyu / OLED siyahı seçenekleri ortak paletten üretilir. Sistem varsayılandır; her cihaz tercihini yerel tutar. Yeni hesap servisi, telemetri veya senkronizasyon eklenmedi. Dağıtımlar önizlemedir.

## Doğrulama

- Windows backend: `python -m unittest discover -s interface/desktop/backend -p 'test_*.py' -q`. 120 test geçti. Yeni tema testleri eski şifreli depo ve yedeğin varsayılanla açılmasını, dört tercihin şifreli saklanmasını, geçersiz tercihin reddini, hesap/mola/planlama/son hata korunmasını sınar. Instagram isteği yoktur.
- `npm run check` ortak tema üretimini, 834 mesajlı yerel Türkçe/İngilizce kataloğu ve JavaScript sözdizimini doğrular. `node --test desktop/*.test.cjs`: 25 test geçti.
- `node scripts/check-appearance.mjs`: gerçek paketlenmiş Windows EXE/worker ve Edge web önizlemesinde 8 senaryo grubu. Windows şifreli kayıt/yeniden açılış, native tema, sistem medya değişimi ve açık seçim üstünlüğü; 6 Windows rotası, palet/modal/arşiv, İngilizce ayarlar ve 960 piksel pencere; webde sistem değişimi, yeniden yükleme, geçersiz tercih ve 5 rotanın 1440/390 piksel görünümü sınanır. Başlıca metin/yüzey, ikincil metin, vurgu, düğme ve eklenen/silinen metin renk çiftleri için hesaplanan kontrast en az 4,5:1'dir. Bu bütün ekranlar için bağımsız erişilebilirlik sertifikası değildir. JPEG fotoğraflarında CSS filtre/ters çevirme yoktur.
- 30 mevcut fonksiyonel EXE kontrolü, 9 tarama ilerlemesi ve 10 kısayol/boş ekran kontrolü geçti. Sentetik `TrackerQA-*` depoları ve gerçek Instagram erişimini reddeden worker test kipi kullanıldı. Dış arayüz isteği ve JavaScript hatası: 0. Yerel ekran görüntüleri/rapor `artifacts/appearance-ui/` altındadır.
- Android: 84 birim testi geçti; `:app:lintRelease`, release/debug ve test APK derlemeleri başarılı. Son lint raporu: 0 hata, 14 uyarı. `scripts/check-locales.py`: 556 eşleşen kaynak, yer tutucu ve çoğul kontrolü geçti. İmzalı üretim APK'sı `scripts/verify-release.py --sdk ...` ile ayrıca doğrulandı; sürüm 0.1.32 / versionCode 33, beklenen izinler, kapalı debug/yedek ve açık metin trafik engeli korundu.
- Android emülatöründe `AppearanceFlowTest`, `LanguageFlowTest`, `VisualHistoryScreenTest`: 7 test geçti. Gerçek tema menüsüyle açık/koyu/OLED seçimi, yeniden oluşturma, tekrar açılış, sistemin açık/koyu değişimi, sistem çubuğu görünümü, 429 molası ve hesap verisinin korunması doğrulandı. Görünüm değişirken açılışta otomatik yenileme tercihi açık olsa da yeni profil isteği başlamadığı kontrol edildi. Dil ve görsel arşiv regresyonları da geçti. Testler ayrı debug paketindeki sentetik offline preview kayıtları kullanır.

İlk Android denemesi API 37 emülatörüne ayrılan 1536 MiB bellekte sistemin düşük bellek nedeniyle test sürecini öldürmesiyle kesildi; uygulama istisnası tespit edilmedi. Aynı emülatör 3072 MiB ile yeniden başlatıldı; odaklı testler geçti. Son kaynak derlemesinden sonra aynı yedi test `adb shell am instrument -w -r -e class ...` ile tekrar geçti; sentetik açık/koyu/OLED ekran görüntüleri alındı. Kullanıcı telefonu veya gerçek hesap kullanılmadı. Kaynakların XML çıktısı yalnız native stillerin kullandığı renkleri içerir; programatik görünümler aynı kaynaktan üretilen paleti kullanır.
